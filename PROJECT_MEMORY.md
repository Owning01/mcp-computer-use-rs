- F6 (optimizacion RAM del puente, 2026-10-19): el puente arrancaba el hijo Node (origen) SIEMPRE al inicio, asi que cada sesion opencode pagaba 76 MB de Node sin usar nada proxieado (10 sesiones = 653 MB; el servidor Rust pesa 10,5 MB).
